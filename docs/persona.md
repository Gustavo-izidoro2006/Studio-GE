# Persona — Studio GE

## Instrutor/dono do studio
- É quem usa o app, sozinho — não há outros perfis de usuário na v1
- Responsável por cadastrar os alunos, acompanhar medidas e montar os treinos
- Perfil não-técnico — precisa de uma interface simples, sem jargão, com poucos passos por tela
- Atende alunos de diferentes faixas etárias (de adolescentes a idosos), então precisa registrar adaptações de treino individualizadas
- Hoje provavelmente organiza essas informações de forma manual/informal (papel, planilha, app genérico de anotações) — o app substitui esse processo

## O que ele precisa do app
- Encontrar rápido as informações de um aluno específico
- Registrar uma nova medida/avaliação sem fricção
- Montar ou ajustar um treino sem digitar tudo do zero toda vez
