# Spec — UI base (navegação e paleta)

## Paleta
- Azul (primário/header/ativo): `#185FA5`
- Amarelo (destaque/indicador): `#EF9F27`
- Branco (fundo): `#FFFFFF`

## Estrutura de tela
- **Header:** ícone de menu (esquerda), título centralizado com nome da tela atual, ícone de ação (direita — ex: adicionar)
- **Navegação:** bottom tab bar fixa, 4 abas — Alunos, Exercícios, Treinos, Perfil
  - Aba ativa: ícone e texto em azul, indicador amarelo (barra fina) embaixo
  - Aba inativa: ícone e texto em cinza

## Critérios de aceite
- [ ] A aba ativa muda visualmente ao navegar entre telas
- [ ] O header sempre reflete o nome da tela atual
- [ ] Layout consistente entre as 4 telas principais
